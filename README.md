## 1차 방향

- 개역한글 1961을 기본 한국어 역본으로 사용
- 책/장 즉시 이동
- 이전/다음 장
- 글자 크기·행간·본문 폭 조절
- 다크 모드
- 절 복사
- 마지막 읽던 위치 로컬 저장
- 여러 역본을 추가할 수 있는 구조
- 로그인·결제·서버·광고는 1차 MVP에서 제외

## 본문 권리

개역한글 1961의 저작재산권 보호기간은 만료되었으며, 대한성서공회의 성명표시권과 동일성유지권을 준수합니다.

초기 데이터 소스 후보: `bluesaurel/Korean-Bible-1961-KRV`의 JSON 데이터. 공개 서비스 전에는 공식 본문과의 무결성을 다시 검수합니다.

## 기술 방향

1차 MVP는 빌드 과정 없이 실행 가능한 정적 HTML/CSS/JavaScript로 시작합니다. 제품 가치가 확인된 뒤에만 구조를 확장합니다.
